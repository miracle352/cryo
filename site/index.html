How it works

    
Freeze. Restart. Thaw.

    
Cryo is one Python file on top of CRIU, Linux's checkpoint/restore tool. It runs as a Sprite service and needs nothing from Fly.

  

  

    
01 · RUN
Start your agent under cryo

      
Cryo launches it as root in a small seccomp sandbox that switches off the two kernel features CRIU can't save on a Sprite.

      sudo cryo run cc --tmux -- claude

    
02 · FREEZE
Snapshots while it works

      
Every minute cryo dumps the whole process tree (memory, terminals, sockets) to disk without stopping it. Claude Code: about half a second.

      cc: frozen in 0.48s (188 MB)

    
03 · THAW
Back after any restart

      
When the Sprite comes back, the cryo service notices, restores every agent from its last snapshot and emails you.

      cc: thawed in 0.17s as pid 15296

What we learned about Sprites

    
Five things that make this hard. And how cryo gets around them.

    
Found by testing on a real Sprite (kernel 6.12.87-fly). Written up for the Fly.io team.

  

  

    
01
Root can't ptrace other users' processes
The Sprite drops CAP_SYS_PTRACE, so CRIU can't freeze a process owned by the sprite user.
→ cryo starts every agent as root, so they share an owner

    
02
No CAP_SYS_TIME
Restoring a time namespace fails with "Unable to set a monotonic clock offset".
→ cryo drops the timens image; the process just sees its clock jump

    
03
No CAP_DAC_READ_SEARCH
CRIU can't reopen inotify watches by file handle, so any agent that watches its config can't be frozen.
→ seccomp makes inotify unavailable; agents fall back cleanly

    
04
Overlay root mixes device numbers
Directories report the overlay's device, regular files report the lower layer's. Inotify watches on files can't be matched to a path at all.
→ same seccomp filter; also io_uring, which CRIU can't dump

    
05
boot_id survives a checkpoint restore
A restore restarts the container, not the kernel. The forum's advice to detect restarts with boot_id misses it.
→ cryo pairs boot_id with the start time of PID 1

Install

    
Three commands on any Sprite.

  

  
sudo apt-get install -y criu tmux
git clone https://github.com/miracle352/cryo && cd cryo
sudo env PATH="$PATH" HOME=$HOME ./cryo run myagent --tmux -- claude
sudo env PATH="$PATH" HOME=$HOME ./cryo install --api     # thaw on every boot
