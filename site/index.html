How it works

Freeze. Restart. Thaw.

One Python file on top of CRIU, Linux's checkpoint/restore tool. It runs as a Sprite service and needs nothing new from Fly.

1

Run it under cryo

Cryo starts your agent inside a tiny seccomp sandbox that switches off the two kernel features CRIU can't save on a Sprite.

2

It freezes on activity

When the agent does something and goes quiet, cryo dumps its whole process tree to disk without stopping it. Claude Code: under half a second.

memory pages
3

It thaws after any restart

When the Sprite comes back, the cryo service sees the agent died, restores it from disk and emails you.

agent heartbeat
Why it matters

Your agent keeps its mind.
Not just its files.

COLD WAKES · HOST MOVES

Survives what Sprites can't

Fly's own docs say processes are lost on a cold wake. Cryo puts them back: the conversation, the REPL variables, the half-finished task.

CHECKPOINT RESTORE

Rewind the disk, keep the agent

A Sprite checkpoint saves files, not processes. Cryo's snapshots live on disk, so a restore brings your running agents back too.

ACTIVITY-DRIVEN

Snapshots when something happens

Cryo watches CPU time instead of a clock. Idle agents cost nothing; busy ones are re-frozen seconds after they finish.

SPRITES CONNECTOR

Tells you it survived

Alerts go out through the Resend connector. The API key never touches the Sprite; the gateway adds it on the way out.

What we learned about Sprites

Five walls. Five ways around.

Found by testing on a real Sprite (kernel 6.12.87-fly) and written up for the Fly.io team.

01 · CAP_SYS_PTRACE

Root can't trace other users' processes

CRIU can't freeze anything owned by the sprite user.

→ cryo runs agents as root, same owner as CRIU
02 · CAP_SYS_TIME

Time namespaces can't be restored

"Unable to set a monotonic clock offset."

→ cryo drops the timens image; the clock just jumps
03 · CAP_DAC_READ_SEARCH

Inotify watches can't be reopened

Any agent that watches its config file becomes un-freezable.

→ a seccomp filter turns inotify off for agents
04 · OVERLAY ROOT

Files and folders report different devices

Watched files can't be matched to a path even by scanning. io_uring can't be dumped either.

→ same filter blocks inotify and io_uring
05 · BOOT_ID

A checkpoint restore keeps the same boot_id

It restarts the container, not the kernel. Detecting restarts by boot_id misses it.

→ cryo pairs boot_id with PID 1's start time
06 · BONUS

Timers count awake time

A paused Sprite freezes every process, so "every 60s" can mean much longer.

→ cryo snapshots on activity, not on a clock
